# ListingMuse DB Schema (Postgres)

Notes:
- Primary keys use `uuid` generated by the application.
- All tenant data is scoped by `shop_id`.
- Store external IDs as `text` (Shopify GIDs, Lemon Squeezy IDs) to avoid coupling to numeric formats.
- Consider encrypting sensitive fields (e.g., Shopify access tokens) at the application layer.

## Extensions
Recommended:
- `pgcrypto` (optional) for `gen_random_uuid()` if desired.

## Tables

### shops
Represents an installed Shopify shop.

Columns:
- `id uuid primary key`
- `shop_domain text not null unique` (e.g., `mystore.myshopify.com`)
- `shop_gid text` (Shopify GraphQL shop GID, optional)
- `is_active boolean not null default true`
- `installed_at timestamptz not null default now()`
- `uninstalled_at timestamptz`
- `access_scopes text not null default ''`
- `offline_access_token_enc text` (encrypted blob)
- `offline_token_expires_at timestamptz` (if applicable)
- `billing_status text not null default 'unpaid'` (e.g., `unpaid|trial|active|past_due|canceled`)
- `created_at timestamptz not null default now()`
- `updated_at timestamptz not null default now()`

Indexes:
- `shops_shop_domain_uq` on (`shop_domain`) unique

### users
Represents a user who authenticated into the embedded app.

Columns:
- `id uuid primary key`
- `shop_id uuid not null references shops(id) on delete cascade`
- `shopify_user_gid text` (Shopify user/admin GID)
- `email text`
- `display_name text`
- `role text not null default 'member'` (e.g., `owner|admin|member`)
- `last_login_at timestamptz`
- `created_at timestamptz not null default now()`
- `updated_at timestamptz not null default now()`

Constraints:
- unique (`shop_id`, `shopify_user_gid`)

Indexes:
- `users_shop_id_idx` on (`shop_id`)

### subscriptions
Tracks Lemon Squeezy subscription state per shop.

Columns:
- `id uuid primary key`
- `shop_id uuid not null references shops(id) on delete cascade`
- `provider text not null default 'lemonsqueezy'`
- `ls_subscription_id text not null`
- `ls_customer_id text`
- `ls_order_id text`
- `ls_user_email text`
- `ls_product_id text`
- `ls_variant_id text`
- `ls_product_name text`
- `ls_variant_name text`
- `status text not null` (e.g., `on_trial|active|past_due|paused|unpaid|cancelled|expired`)
- `renews_at timestamptz`
- `ends_at timestamptz`
- `trial_ends_at timestamptz`
- `billing_anchor text`
- `current_period_start timestamptz`
- `current_period_end timestamptz`
- `cancel_at_period_end boolean not null default false`
- `payment_processor text` (e.g., `stripe|paypal`)
- `card_brand text`
- `card_last_four text`
- `pause jsonb` (pause configuration)
- `test_mode boolean not null default false`
- `included_credits integer not null default 0`
- `metadata jsonb not null default '{}'::jsonb`
- `created_at timestamptz not null default now()`
- `updated_at timestamptz not null default now()`

Constraints:
- unique (`provider`, `ls_subscription_id`)
- unique (`shop_id`) (optional: if only one active subscription per shop)

Indexes:
- `subscriptions_shop_id_idx` on (`shop_id`)

### products
Cached Shopify product snapshot (optional but useful for batch UX).

Columns:
- `id uuid primary key`
- `shop_id uuid not null references shops(id) on delete cascade`
- `shopify_product_gid text not null`
- `handle text`
- `title text`
- `vendor text`
- `product_type text`
- `status text` (Shopify status)
- `image_urls jsonb not null default '[]'::jsonb`
- `tags text[] not null default '{}'`
- `last_synced_at timestamptz`
- `created_at timestamptz not null default now()`
- `updated_at timestamptz not null default now()`

Constraints:
- unique (`shop_id`, `shopify_product_gid`)

Indexes:
- `products_shop_id_idx` on (`shop_id`)
- `products_handle_idx` on (`shop_id`, `handle`)

### generations
Stores AI generation requests and results.

Columns:
- `id uuid primary key`
- `shop_id uuid not null references shops(id) on delete cascade`
- `user_id uuid references users(id) on delete set null`
- `mode text not null` (`single|batch`)
- `status text not null` (`queued|running|succeeded|failed|canceled`)
- `source text not null default 'ui'` (`ui|api|webhook`)
- `request jsonb not null` (inputs: product id, images, options)
- `result jsonb` (outputs: structured attributes + copy)
- `error_code text`
- `error_message text`
- `provider text not null default 'openai'` (or other)
- `model text`
- `prompt_version text not null default 'v1'`
- `tokens_in integer not null default 0`
- `tokens_out integer not null default 0`
- `cost_cents integer not null default 0`
- `credits_charged integer not null default 0`
- `started_at timestamptz`
- `completed_at timestamptz`
- `created_at timestamptz not null default now()`
- `updated_at timestamptz not null default now()`

Indexes:
- `generations_shop_id_created_at_idx` on (`shop_id`, `created_at` desc)
- `generations_status_idx` on (`shop_id`, `status`)

### usage_ledger
Immutable record of credit usage and adjustments.

Columns:
- `id uuid primary key`
- `shop_id uuid not null references shops(id) on delete cascade`
- `user_id uuid references users(id) on delete set null`
- `event_type text not null` (`generation|apply|refund|adjustment|subscription_grant`)
- `reference_type text` (`generation|apply|subscription|manual`)
- `reference_id uuid`
- `credits_delta integer not null` (negative = spend, positive = grant)
- `description text`
- `metadata jsonb not null default '{}'::jsonb`
- `created_at timestamptz not null default now()`

Constraints:
- unique (`event_type`, `reference_type`, `reference_id`) deferrable initially immediate (optional idempotency)

Indexes:
- `usage_ledger_shop_id_created_at_idx` on (`shop_id`, `created_at` desc)
- `usage_ledger_reference_idx` on (`reference_type`, `reference_id`)

### webhooks
Stores webhook deliveries for idempotency and troubleshooting.

Columns:
- `id uuid primary key`
- `shop_id uuid references shops(id) on delete cascade` (nullable for pre-install events)
- `provider text not null` (`shopify|lemonsqueezy`)
- `topic text not null` (Shopify topic or Lemon Squeezy event name)
- `external_id text` (delivery id / event id if provided)
- `signature_valid boolean`
- `received_at timestamptz not null default now()`
- `processed_at timestamptz`
- `status text not null default 'received'` (`received|processed|failed|ignored`)
- `attempts integer not null default 0`
- `last_error text`
- `payload jsonb not null`

Constraints:
- unique (`provider`, `external_id`) (if external_id exists)

Indexes:
- `webhooks_shop_id_received_at_idx` on (`shop_id`, `received_at` desc)
- `webhooks_provider_topic_idx` on (`provider`, `topic`, `received_at` desc)

### audit_log
Immutable audit trail of user and system actions.

Columns:
- `id uuid primary key`
- `shop_id uuid not null references shops(id) on delete cascade`
- `user_id uuid references users(id) on delete set null`
- `action text not null` (e.g., `auth.login`, `generation.create`, `generation.apply`, `billing.update`)
- `entity_type text` (e.g., `product`, `generation`, `subscription`)
- `entity_id uuid`
- `ip text`
- `user_agent text`
- `metadata jsonb not null default '{}'::jsonb`
- `created_at timestamptz not null default now()`

Indexes:
- `audit_log_shop_id_created_at_idx` on (`shop_id`, `created_at` desc)
- `audit_log_action_idx` on (`shop_id`, `action`, `created_at` desc)
